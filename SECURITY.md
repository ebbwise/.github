# Security Policy

Ebbwise stores personal health data, so security reports get priority.

## Reporting a Vulnerability

Report security vulnerabilities privately using this repository's GitHub
Security Advisories (the repo's **Security** tab → **Report a vulnerability**),
rather than opening a public issue.

If a repository doesn't have private vulnerability reporting enabled, email
13117393+austek@users.noreply.github.com instead.

You should expect an initial response within three working days. If the issue
is confirmed, a fix will be prepared and a security advisory published once
it's available. Any incident affecting personal data is also assessed for
reporting to the ICO within 72 hours.
